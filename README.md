# hq-skills

Три скилла цикла задач для штаба на [hq-starter](https://github.com/harnessmachine/hq-starter) v3: `daily`, `retro`, `planning`.

Они читают `TASKS.md` и журналы `tasks/<slug>/task.md`. Писать в задачи может только `manager`, сами скиллы задачи не меняют.

| Скилл | Когда | Что делает | Что пишет |
| --- | --- | --- | --- |
| `/daily` | утром | Показывает, что ждёт тебя, фокус недели и одну задачу для старта | ничего, ответ в чате |
| `/retro` | конец недели | Срез по журналам, решение по каждой незавершённой задаче | `reports/ГГГГ-WNN-retro.html` |
| `/planning` | после ретро | Выбирает 1–3 результата следующей недели | `reports/ГГГГ-WNN-plan.html` |

Скиллы запускаются командой, сами не включаются. `retro` честно останавливается, если за неделю нет записей в журналах.

## Установка

Открой агента в штабе (Claude Code или Codex) и вставь:

```text
Установи в этот штаб скиллы из https://github.com/harnessmachine/hq-skills/tree/v1 : daily, retro, planning.
Прочитай README.md этого репозитория и сделай установку по разделу «Что менять в штабе». Сначала покажи план таблицей «файл — что будет» и дождись моего «да».
```

## Что менять в штабе

1. Скопировать папки из `skills/` в `.agents/skills/` штаба. Одноимённые скиллы не перезаписывать молча: сначала показать, что совпало.
2. В таблицу «Скиллы» файла `AGENTS.md` добавить:

   ```markdown
   | `daily` | владелец | Утром: что ждёт меня, фокус недели, с чего начать. Ничего не меняет |
   | `retro` | владелец | Конец недели: срез по журналам задач, решения по незавершённому, отчёт в `reports/` |
   | `planning` | владелец | После ретро: 1–3 результата недели, задачи через `manager`, план в `reports/` |
   ```

3. В таблицу «Что где лежит» добавить:

   ```markdown
   | `reports/` | Недельные отчёты ретро и планы. Исторические снимки, не источник состояния |
   ```

4. Проверить, что `.claude/skills` — симлинк на `.agents/skills`.

Проверка: в новом чате `/daily` называет фокус и одну задачу.

## Цикл

```text
planning (понедельник) → daily → «продолжаем задачу <slug>» → работа → manager пишет журнал
                       → daily → … → retro (пятница) → planning
```
